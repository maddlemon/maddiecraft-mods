# Maddiecraft mods

Small NeoForge 1.21.1 mods by Maddie for the Maddiecraft modpack. The jars are hosted here so the pack can download them by URL.

| Mod | Version | Jar | What it does |
|---|---|---|---|
| Chunk Claims | 2.0.0 | `mods/chunkclaims-2.0.0.jar` | Claim chunks to protect builds, chests and animals, and trust other players. Includes a claims map, and shows claims on JourneyMap if it's installed. |
| Curio Slot Admin | 1.0.0 | `mods/curioslotadmin-1.0.0.jar` | Add, resize and remove Curios slots for every player from an in-game admin screen (`/curioslots`). Needs Curios. |
| Aviator's Goggles | 1.0.0 | `mods/aviatorhat-1.0.0.jar` | Only the Aviator's Goggles from Create: Aeronautics. With Create installed it also works as Create goggles. |

All three need Minecraft 1.21.1 and NeoForge 21.1, on both the client and the server.
